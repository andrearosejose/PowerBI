Power BI Monthly Sales Analysis Project

This repository contains a Power BI Desktop project focused on analyzing and
visualizing monthly sales performance through interactive dashboards.
The project transforms raw sales data into meaningful insights, enabling
effective tracking of trends, KPIs, and overall business performance.

The dashboard is designed with a clean layout and interactive visuals,
making it suitable for business reporting and portfolio presentation.


PROJECT OBJECTIVE

The objective of this project is to build a professional sales analytics
dashboard that helps users:

Analyze monthly sales performance
Track revenue and quantity metrics
Identify top-performing products and categories
Understand sales trends and patterns
Support data-driven decision-making
